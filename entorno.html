Mi entorno de trabajo

qué ocurre desde que escribes una URL hasta que ves la página

Primero, escribes la URL. Segundo, ocurre la resolución DNS con la que el navegador averigua la IP del dominio. En tercer lugar ocurre la conexión tcp, donde el navegador abre una conexión con el servidor en el puerto correspondiente. En cuarto lugar el servidor procesa y responde con el HTML y por último el navegador pinta la página

qué herramientas usas (VS Code, extensiones, Live Server, Git) y para qué

Utilizo VS Code para escribir y editar código. Dentro de VS code utilizo la extensión "Live Server", que me permite ver la previsualización de mi página. Por último utilizo Git, que se sincroniza con mis carpetas de VS Code, para guardar todo el proceso de mis proyectos.
